# 揭棋连线自动走棋（Line Connect）

在原「图片识别」能力之上，为 JieqiBox 增加了在别的对弈平台（天天象棋等）上自动落子的功能。

> 本分支包名为 `com.jieqibox.lineconnect`，与官方 JieqiBox（`com.jieqibox.app`）不同，
> 可以同时安装、配置互不干扰。

## 原理

```
对弈 App 画面 ──(MediaProjection 截屏)──▶ 前台服务缓存最新帧
        │
        ▼  base64 JPEG
   Vue 前端连线面板 ──(best.onnx / onnxruntime-web)──▶ 识别棋盘与棋子
        │
        ▼  10×9 检测结果 → 揭棋 FEN（含暗子池）
   UCI 引擎（Pikafish 揭棋版）分析
        │
        ▼  bestmove (如 h2e2)
   屏幕坐标换算 ──(无障碍 dispatchGesture)──▶ 对弈 App 自动落子
```

与原有「图片识别」的区别：图片识别是**手动选一张图**导入局面，连线是**持续截屏 + 自动分析和落子**。

## 使用流程

1. **装引擎**（只需一次）
   - 在电脑上下载 Pikafish 揭棋分支的 Android 可执行文件：
     <https://github.com/official-pikafish/Pikafish/tree/jieqi>
   - 在 JieqiBox 工具栏打开「引擎管理」，选择该文件；App 会把它复制到私有目录并赋予执行权限。
2. **开权限**（只需一次）
   - 工具栏点击「连线自动走棋」图标（粉色接入点图标）。
   - 点「申请截屏权限」，系统弹窗中选择要共享的屏幕/应用。
   - 点「打开无障碍设置」，启用「JieqiBox 自动走棋」。可用「测试点击」验证是否生效。
3. **连线**
   - 切到对弈 App，进入一局揭棋，轮到你走时切回 JieqiBox，点「开始连线」。
   - App 会每 ~0.9 秒截一次屏，识别到局面稳定后交给引擎，然后把着法点击/拖拽到对弈 App 上。
   - 之后再切回对弈 App 即可，前台服务会让截屏和轮询继续运行。

> **建议先开「演练模式」**：只识别、只分析、只打日志，不真的点击。确认识别稳定后再关闭。

## 参数

| 参数 | 说明 |
| --- | --- |
| 我方执子 | 红 / 黑，决定引擎分析的走子方 |
| 落子方式 | `两次点击`（点起点→点终点）或 `拖拽` |
| 识别间隔 | 每轮截屏的间隔，默认 900ms |
| 思考时间 | 每步交给引擎的 movetime |
| 截屏缩放 | 截屏分辨率比例；太低会导致棋子太小识别不到 |
| 稳定帧数 | 连续多少帧识别结果一致才认为局面稳定 |
| 点击间隔 | 两次点击之间的等待 |
| 演练模式 | 只分析不点击 |

## 安全与边界

- **截屏权限**由系统弹窗授予，随时可在系统设置中撤销。
- **无障碍服务**只用于发送点击/滑动手势，配置里 `canRetrieveWindowContent` 之外不读取界面内容，也不上传任何数据。
- 识别完全在设备本地用 ONNX 模型完成；引擎也在本地运行。
- 请遵守对弈平台的使用条款，本功能仅用于本地研究/辅助。

## 依赖的原生组件（仅 Android）

| 文件 | 作用 |
| --- | --- |
| `ScreenCaptureService.kt` | MediaProjection 前台服务，缓存最新帧为 JPEG |
| `AutoPlayAccessibilityService.kt` | 无障碍手势注入（tap / swipe） |
| `LineConnectBridge.kt` | `window.LineConnect` JS 接口 |
| `MainActivity.kt` | 注册桥接、处理截屏授权回调 |
